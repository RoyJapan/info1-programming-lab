# 情報Ⅰ プログラミング演習室

コードとブロックで共通テスト風のプログラムを作り、ブラウザー内で実行できる学習サイトです。iPad Safariとタッチ操作に対応する静的Webアプリです。

## できること

- ブロック表示で開き、置き場からドラッグまたはタップでブロックを積める（演算子は共通テストの表記で表示し、意味の説明を添える）。「コード」で共通テスト表記のコードを表示・編集
- 配列添字は0始まりが標準（個別問題の指定を優先。画面で切り替え可。既存の保存済みプログラムは設定を維持）
- 行数表示の右でプログラムの文字サイズを16〜32pxの整数で指定（コード・行番号・ブロックに反映し、この端末に設定を保存）
- 予想出力と実行出力の比較
- 1行ずつの実行トレース、自動再生、一時停止、1ステップ送り
- 過去問コード2本（原文の配列名・変数名・データ・処理を保持、空欄補完済み）
- この端末への自動保存とJSONの読み書き
- 初回読み込み後のオフライン利用（対応ブラウザー）

アカウント、教材サーバー、コード送信、外部ライブラリーは使いません。作成したコードと実行記録はブラウザーのローカル保存領域に残ります。端末間の移行には「書き出し」を使ってください。

## 起動

index.htmlを静的ホスティングへ配置して開きます。ローカルで動かす場合は、プロジェクトフォルダーで次を実行します。

    python -m http.server 8000

その後 http://localhost:8000/ を開きます。サービスワーカーによるオフライン利用にはHTTPSまたはlocalhostが必要です。


## 対応するプログラム表記

- 公式表記の変数名は英字から始め、配列名は大文字から始めます。教材の読みやすさのため、日本語の変数名も使えます。
- 変数への代入（`a = 1 , b = 2` のように1行に複数も可）、数値/文字列/真偽値、一次元・二次元配列（`Data[2,4]`）
- `Dataのすべての値を0にする`
- 0始まり（標準）または1始まりの配列添字。問題文で指定された始まり方を優先します。
- 算術（`÷` は商の整数部分、`%` は余り）、比較、論理演算
- `もし … ならば:` / `そうでなくもし … ならば:` / `そうでなければ:`
- `増やしながら` / `減らしながら` の回数繰返し、`… の間繰り返す:`
- 表示、`【外部からの入力】`（`入力()` も可）、`#` 以降のコメント
- 要素数、最大値、最小値、整数、乱数
- 全角の記号・数字・空白は、文字列の外では半角として読みます。`iを0から9まで1ずつ…` のように空白を省いても読めます。

大学入試センターの「共通テスト用プログラム表記の例示」にある二分探索のプログラムは、そのまま実行できます（tests/runtime.test.js で確認）。

## テスト

    node --test

乱数()は0以上1未満の数を返します。乱数を使うプログラムは実行ごとに結果が変わることがあります。

利用者のコードをJavaScriptとして実行しません。実行量、配列、出力、トレースには上限があります。共通テスト用プログラム表記の完全互換を目標とせず、未対応の書き方はエラーで知らせます。

## 教材の出典と位置付け

過去問コードは、大学入試センターの公式問題に基づき、原文の配列名・変数名・データ・処理を保持しています。実行用に空欄を補い、行番号・字下げ記号・表示文の折返しだけをエディターに合わせています。説明文は本サイトで作成しています。試験PDFや図は同梱していません。

- 令和7年度 本試験 第3問 問3 図5: [大学入試センター公式問題](https://www.dnc.ac.jp/kyotsu/kakomondai/r7/r7_honshiken_mondai.html) — `Nissu`・`Akibi`を使った工芸品の担当と期間の割当て
- 令和8年度 本試験 第3問 問2 図2: [大学入試センター公式問題](https://www.dnc.ac.jp/kyotsu/kakomondai/r8/r8_honshiken_mondai.html) — `Touchaku`・`Kaishi`・`Shuryou`を使った待ち時間の計算

更新前に保存したプログラムは上書きしません。新しい過去問コードを使う場合は「教材」から読み込み直してください。

最新の公式問題は[大学入試センターの過去問ページ](https://www.dnc.ac.jp/kyotsu/kakomondai/)で確認してください。

## プライバシーと保存

- コード、入力値、予測、記録はこの端末のブラウザー内だけに保存します。
- ブラウザーのサイトデータ消去や端末変更に備え、定期的にJSONを書き出してください。
